# WeaponPaints category icons

Place the category SVG files in this directory using these exact names:

- inventory.svg
- skins.svg
- rifles.svg
- smg.svg
- heavy.svg
- pistols.svg
- snipers.svg
- knives.svg
- gloves.svg
- agents.svg
- music.svg
- pins.svg

Public paths are served from `/img/weaponpaintsicons/<name>.svg`.

Recommended source format: square SVG, `viewBox="0 0 24 24"`, transparent background, and artwork centered with consistent internal padding. The page includes a Font Awesome fallback until each SVG file is present, so the sidebar remains usable while icons are being uploaded.
